# 序曲 临界线上的寂静

> 素数像一群桀骜不驯的野马，没人能预测下一匹何时跃出山脊；可只要你退后一步，听见它们蹄声汇成的和弦，整座山谷却只沿着一条直线共鸣。

一百六十多年来，黎曼猜想一直是数学里最耀眼也最磨人的灯塔。有人把它供在玻璃罩里，说它是“千禧年大奖难题之首”，仿佛靠近它之前必须先背完十本厚重的复分析与代数几何教材。

让我们先把这层神秘的祭坛掀开。黎曼猜想问的其实是一件非常朴素的事：**数一数不超过 $x$ 的素数有多少个，真实的素数个数和光滑预测之间，到底会偏离多远？**

你可以把素数想象成一串随手抛硬币的结果。如果你抛 $x$ 次均匀硬币，正面次数大约是 $x/2$，而随机起伏的幅度大约是 $\sqrt{x}$——不会大到 $x^{0.8}$，也不会小到纹丝不动，就是 $\sqrt{x}$ 量级。黎曼在 1859 年那篇只有八页的短文里发现，素数的分布竟然也有一副“频谱”：决定素数起伏有多剧烈的，正是黎曼 $\zeta$ 函数在复平面上的一串零点 $\rho = \sigma + i t$。每一个零点，都像一根振动着的琴弦，给素数计数加上一波幅度约为 $x^{\sigma}$、频率为 $t$ 的涟漪。

如果所有非平凡零点都老老实实排在实部 $\sigma = \frac{1}{2}$ 的竖直线上，那每一波涟漪的振幅都不超过 $\sqrt{x}$——素数就像自然界能造出的最均匀、最克制的随机序列。反过来，哪怕**只有一个**零点偷偷溜到了 $\sigma = 0.72$，它发出的那一道浪就会按 $x^{0.72}$ 疯狂膨胀，彻底撕裂 $\sqrt{x}$ 的宁静。

> 一条直线之所以神圣，不是因为人们崇拜对称，而是因为只要偏离它一毫米，整个素数世界就会失声走调。

这份形式化源码体量惊人：175,187 个 `.lean` 文件，超过 1,737 万行代码，818,755 条定理与引理，没有一行注释，也没有一个 `sorry` 或自定义公理。任何人直接打开目录树，都会像走进一座没有路标的巨型钟表厂。

面对这样的庞然大物，最糟糕的读法是逐行抄写符号；最聪明的读法是先问三个费曼式的问题：

1. **最后一道门锁在哪里？** 证明究竟需要拿下什么条件，才能一锤定音锁死所有零点？
2. **卡住数学界一百五十年的那堵墙是什么？** 为什么老办法在这里撞得头破血流？
3. **新证明到底用了哪几步“反直觉的绝招”翻过那堵墙？**

当你把千万行脚手架剥开，里面的承重主梁其实出奇地清晰，一共只有七级台阶——恰好对应本书的七章：

1. **[第一章 对称之镜](ch01-the-mirror-on-half.md)**：函数方程在 $\operatorname{Re}(s) = \frac{1}{2}$ 处立起一面双面镜。只要证明所有狄利克雷 $L$ 函数在右半平面 $\operatorname{Re}(s) > \frac{1}{2}$ 里**一个零点也没有**，左半平面的零点就会被镜子一并清空，所有非平凡零点无路可逃，只能全部落在 $\frac{1}{2}$ 这条线上。
2. **[第二章 素数的影子与朗道陷阱](ch02-prime-shadow-and-landau.md)**：怎么证明右半平面没有零点？不必一个个去抓复平面上的零点，只需盯住实轴上由素数算出来的平滑加权和 $G_z(x)$。朗道的非负积分陷阱告诉我们：只要 $G_z(x)$ 守住单侧边界，右半平面就不可能藏着零点。于是复平面上的捉迷藏，变成了实数线上的符号与大小账本。
3. **[第三章 给整数求导](ch03-differentiating-integers.md)**：在有限域的函数世界里，斯捷潘诺夫（Stepanov）靠“造一个在每个点高重数消失的辅助多项式”几页就拿下了类似问题。可整数不能直接求导，怎么凭空变出重数 $m$？答案是借 CM 椭圆曲线上的不变导数与福克（Fock）空间上的分次外尔（Weyl）整除性，把“求导”变成代数上的整除结构。
4. **[第四章 $\sqrt{X}$ 面镜子](ch04-chain-of-root-x-mirrors.md)**：这是整座证明里最让人拍案叫绝的一跳。为了在自守形式的世界里原生模拟“求导 $m$ 次”，证明把定酉群上的 Theta 提升首尾相连，串成一条长度高达 $m \sim \sqrt{X}$ 的锁链！再用“跷跷板法则”（Seesaw）把链条尽头的周期积分，翻成与赫克（Hecke）特征无关的贝塞尔（Bessel）周期。
5. **[第五章 冲破 $2/3$ 天花板](ch05-breaking-two-thirds.md)**：每做一次提升都要付出“体积与高度的代价”。如果只盯着单个特征算账，链条走到 $\sigma = \frac{2}{3}$ 就会力竭停步。证明用格斜率（Harder–Narasimhan 最大斜率与博斯特斜率不等式）精确量出每一层的成本，再把一整族赫克特征上的整结构“胶合”起来分摊代价，一举击穿 $\frac{2}{3}$ 的天花板，直抵 $\frac{1}{2}$。
6. **[第六章 贝伦德塔与收网时刻](ch06-behrend-towers-and-closing-the-net.md)**：选岩泽（Iwasawa）塔的层级时，最怕撞上等差数列的共振。证明借来贝伦德（Behrend）的高维整数球壳——球面严格外凸，任何三点都不共线，所以绝不藏着三项等差数列，却又能装下极高密度的整数！再配合局部–整体伽罗瓦表示、小类数估计与稠密阈值窗口，彻底收网，推出所有特征的右半平面无零点定理。
7. **[第七章 一千七百万行代码的骨架](ch07-anatomy-of-17-million-lines.md)**：回到工程与认识论的地面：一部没人能逐行肉眼读完的形式化证明，为什么能比任何纸面手稿更诚实？本章解剖 27 行 `Challenge.lean` 与 Mathlib `v4.33.1` 的接口契约、8,490 块内容寻址分片的公开 CI 构建、任何人四行命令即可执行的 `./verify` 零信任本地重放与多检验器路线，并配有交互验证实验室与专题短片。

## 0.2 本书的阅读方式与证据承诺 {#sec-prelude-evidence}

读这本书不需要你提前记住自守表示、岩泽理论或上同调的定义。每一章都按同一个节奏展开：先拿一个小到能心算的玩具例子（比如 $x=10$ 时的素数和、三维格子里的 9 个球壳点、一条四段折线的斜率屋顶）把“为什么非这么做不可”讲透，再落到精确的定理陈述与 Lean 源码锚点上。

> 真正深刻的工具，在被名字吓倒之前，骨子里往往只是一个非常干脆的算账办法。

本书严格遵守三层证据边界：

- 标有绿色 **LEAN ✓** 的定理、引理、命题与推论，全部直接锚定到 [`the-omega-institute/riemann-hypothesis`](https://github.com/the-omega-institute/riemann-hypothesis) 在所钉提交 `[{commit}](trureturing:)` 下的对应 Lean 4 声明（文末“形式化验证账本”逐条列出文件与行号）。定理框内的数学陈述保持克制与精确，不掺修辞；框外的散文负责直觉、手算、比喻与谱系批判。
- 书中标有 `NUM` 或 `MODEL` 的数值曲线与示意图，只用来帮你把机制看明白，绝不冒充形式化证明本身。
- 终章中标有红色 **OPEN** 的条目，是这份证明**尚未**覆盖、仍然敞开的数学群山（例如一般数域的戴德金 $\zeta$ 函数、更广义的自守 $L$ 函数与零点对关联猜想）。

现在，推开第一扇门：先站到 $\operatorname{Re}(s) = \frac{1}{2}$ 那面镜子面前。
